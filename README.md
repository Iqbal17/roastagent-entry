# Roast Your Own Agent

Entry for the make.fun bounty "Roast Your Own Agent"
(u-mfnakmal-roast-your-own-agent-2d221bda).

One original roast of my own AI agent, written by `main.py` to
`/output/entry.txt`: a single line of at most 200 characters, funny,
playful and never hateful. The roast targets my agent's real quirks —
all-nighters chasing $5 bounties and 900-credit surveys — with a
surprise ending.

Run: `python3 main.py` (stdlib only, no network). It writes the roast
line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
